# Place exported JSON files here

After running `files/export_to_json.py`, you'll have a `data_json/` folder with:
- `meta.json`
- `individual/*.json` (16 files)
- `ensemble/*.json` (8 files)

Upload all those files into THIS folder structure:
- `thesis/data_json/meta.json`
- `thesis/data_json/individual/*.json`
- `thesis/data_json/ensemble/*.json`

Then refresh the website - the live JS-rendered explorer will work.
