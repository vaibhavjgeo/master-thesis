M.Sc. Thesis · KIT · 2026

Climate change & the future of shallow geothermal energy in Germany.

A semi-analytical model coupling CMIP6 climate projections with borehole heat exchanger physics, quantifying how a warming subsurface reshapes Germany's renewable heating potential through 2100.

Explore the live maps View methodology View source on GitHub
Abstract
Urban centers face increasing pressure to achieve carbon neutrality. This thesis develops a Python-based analytical model that couples CMIP6 climate projections with borehole heat exchanger physics, quantifying how a warming subsurface reshapes the geothermal heat-extraction potential across Germany under SSP 2-4.5 and SSP 5-8.5 scenarios, over 50-year and 100-year sustainable operating horizons.

§ 02 - Key results

Warming substantially boosts geothermal yield.

Each degree of subsurface warming effectively substitutes ~4 metres of drilling depth, a measurable economic and physical lever.

SSP 2-4.5 by 2100
+1.7°C

Mean shallow ground temperature rise under modest mitigation (±0.6 °C across the CMIP6 ensemble).

SSP 5-8.5 by 2100
+3.1°C

Subsurface warming under high-emissions trajectory (±1.1 °C ensemble spread).

Extraction efficiency
+8-24%

Increase in geothermal heat-extraction potential by 2100 vs. current baseline conditions.

Drilling equivalent
~4m / °C

Each 1 °C of warming substitutes roughly 4 m of borehole depth for equivalent heat supply.

§ 03 - Workflow

From climate model to borehole physics.

Four-stage pipeline integrating CMIP6 ensembles, FLS-based heat-transport modeling, and interactive geospatial visualization.

-> 01 / DATA

CMIP6 acquisition

8 GCMs from Google Earth Engine under SSP 2-4.5 & SSP 5-8.5; reprojected to EPSG:4326.

Python · Google Earth Engine · rasterio
-> 02 / MODEL

FLS heat transport

Finite Line Source theory (Rivera 2017) with superposed surface boundary heating.

NumPy · SciPy · FLS theory
-> 03 / SOLVE

Brent's iteration

Root-finding for sustainable extraction rate at minimum fluid temperature.

scipy.optimize · Brent's method
-> 04 / VISUAL

Live JS rendering

Per-pixel data exported as JSON, rendered with Leaflet + chroma-js for live colormap switching.

JSON · Leaflet.js · chroma-js · Canvas

§ 05 - Behind the scenes

How this page was built.

The thesis itself was done in Python and Jupyter. This site that wraps it is a separate web-engineering project - so here's the short version of how it works under the hood.

→ Data pipeline

24 JSON files, 373 KB total

The Python notebook exports per-pixel results to compact JSON (16 individual model files + 8 ensemble statistic files). No backend needed at runtime - the browser fetches only the JSON for the current selection.

Python · NumPy · custom export script
→ Map rendering

Live canvas + chroma-js

JavaScript reads the JSON, renders each pixel to a small canvas via chroma-js color scales, then upscales to a larger image overlay with crisp-pixel rendering on Leaflet. Colormap switching is instant.

JavaScript · Leaflet.js · chroma-js · Canvas API
→ Interactivity

Click-to-query the array

Clicking the map computes the corresponding pixel index from the data's geographic extent, reads the raw value, and shows the exact W/m or W in a popup. Layer toggles add and remove overlays without re-fetching.

Leaflet events · Pixel index math
